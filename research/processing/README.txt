炮製文獻資料登錄（processing-evidence-v1）

profiles.json 收錄 15 本草條目的 31 個分支。每個分支分開存放原文明記的
操作、性味/功用字段、精確字位和缺失参数，不以炮製名稱虛構增效係數。
全部分支是古籍文獻記述；modernStandardCorrespondence 均為 unresolved。

證據基底：research/herbs/herbs-and-formulas.json 的 herbs[].rawText。
evidenceSpan.start/end 是 Unicode code point 字位，前含後不含。
basis = herbRawText，herbId 指向原條目；不是 UTF-16 或 byte offsets。
短句已與維基文庫《本草備要》頁面核對，尚未逐本校勘歷史原刊本。
source-checks.json 保留重新取頁的 HTTP/摘要及短句存在檢查；與人工核對不同。

重建：在專案根目錄執行 python3 tools/collect-processing.py。
此程式只重建已選定的短句資料與字位，不會自動把所有古籍敘述判成可信屬性。

身份界線：生地黃條目明記「生掘鮮者」，不把這個鮮品轉成現代乾燥生地黃；
干地黃與熟地黃保持各自條目；乾薑條目的「生用」不是鮮生薑。
附子、白附子、白附片，以及古名芍藥、白芍，不以近似名字自動等同。
甘草條目的「炙」沒有指明蜜，半夏「薑汁拌」沒有核定為现代姜半夏。

屬性界線：明記分支性味的 8 profiles 可以顯示文獻詞標。另 23 profiles
性味未知；未知不作中性，亦不從母條目繼承。工藝或功用有證據不表示
性味已知。歷史「制其毒」「去火毒」等不改寫 modernSafety = unknown。
「制其寒」保留於注記，不轉成溫度、效力或減毒百分比。

参数界線：古籍明記的「七日」「九次」保留於步驟註記。溫度、分鐘、
輔料克數與批量未記即 null。並列可選操作各存分支，不強行串為完整製法。
工藝節錄並非現行合格飲片的完整製造、檢驗或人體給藥流程。

現代規範核查：已開 2025 年版中國藥典頒布公告與湖南 2025 年藥味名稱
規範。公告確認2025年10月1日施行，名稱規範要求飲片規格與投料名稱
清楚對應；尚未取得並逐條核定現行單味炮製標準全文。

稱量界線：此資料集沒有服用劑量。工作台由使用者記錄的克數應有稱量階段、
批次與記錄來源；不能直接把原方的兩、錢、升或枚換成克，不能將輔料質量
等同有效成分量，也不能由克數推算人體藥效。
