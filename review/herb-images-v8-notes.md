# 本草圖片核對（2026-10-05）

本次為現有 340 個本草條目建立可追溯的圖片索引。全部條目至少有一幅參考圖；其中 72 個條目有照片，照片類型包含藥材、藥用部位、來源植物及食品參考。587 個去重後的本地 WebP 檔約 48 MB，圖片完整來源與授權記錄保存在 `dist/downloads/herb-image-catalog.json`。

圖片取自可展示的公有領域古籍圖版及明示開放授權的照片。來源包括《植物名實圖考》、《本草備要圖》、Wellcome、Wikimedia Commons，以及 Wang 等（2020）於 Frontiers in Nutrition 發表的神曲樣品圖（CC BY 4.0）。未把圖片當作古名、現代品種或炮製品的身份認證；各條圖說保留部位、加工狀態、來源歧義等限制。

古籍多格圖版經目視核對後裁出對應格與印刷藥名，並保留完整圖版供使用者對照。其他圖片僅作 EXIF 方向校正、等比例縮小及 WebP 轉存。沒有生成藥材圖片，沒有嵌入未確認展示授權的院校或政府圖片。

驗證結果：

- 圖片完整性工具通過：340 條全部有圖，587 個本地檔案的 SHA-256、尺寸、格式與索引一致；逐幅具有來源、作者或作者未詳註記、授權、圖說與類型。
- 340 個 ID 和條目名称與本草資料庫一致；下載 JSON 與瀏覽器圖片資料一致。
- 修改的 JavaScript 語法及差異格式檢查通過。
- 瀏覽器核對：本草資料庫可搜尋、查看圖片詳情及授權；稱量頁四味圖片正常載入，克數仍留空；炮製頁明示「所選炮製規格另核」。神曲研究样品及古籍原料圖可正常載入。
- 1440 × 960 桌面版與 375 × 812 手機版完成核對，所測資料庫／詳情／工序頁沒有橫向溢出，臨時視窗尺寸已重設。
- 另外抽查荊芥、馬兜鈴、桂枝、桂心、海藻、杜牛膝、枳子、青黛、紫檀、淡豆豉，共 16 幅圖，未發現實質錯配。古名及食品參考限制保留。
